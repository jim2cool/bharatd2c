# LinkedIn Authority Builder

## The 5-Step Authority Framework
1. **Positioning**: Define your niche and who you are helping.
2. **Content Pillars**: Select 3 core topics you will own.
3. **Format Mastery**: Use text-only, carousels (PDF), and image-based posts.
4. **The Hook**: The first 2 lines determine if someone clicks "see more."
5. **Engagement**: Strategically comment on industry peers to build visibility.

## Post Structures
- **The Story Post**: Personal narrative -> Lesson -> Actionable takeaway.
- **The Framework Post**: Step-by-step guide or numbered list.
- **The Hot Take**: Challenging an industry "best practice" with a logical alternative.

## Rules of Engagement
- Avoid the "Corporate Voice."
- Post consistently (at least 3x per week).
- Reply to all comments in the first 60 minutes.
- Value > Vanity (Focus on helpfulness over likes).
