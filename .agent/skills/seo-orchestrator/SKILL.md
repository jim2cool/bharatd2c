# SEO — Universal SEO Analysis Skill

Comprehensive SEO analysis across all industries (SaaS, local services,
e-commerce, publishers, agencies). Orchestrates specialized sub-skills.

## Quick Reference

| Command | What it does |
|---------|-------------|
| `/seo-orchestrator audit <url>` | Full website audit with parallel subagent delegation |
| `/seo-orchestrator page <url>` | Deep single-page analysis |
| `/seo-orchestrator schema <url>` | Detect, validate, and generate Schema.org markup |
| `/seo-orchestrator content <url>` | E-E-A-T and content quality analysis |
| `/seo-orchestrator geo <url>` | AI Overviews / Generative Engine Optimization |
| `/seo-orchestrator programmatic [url|plan]` | Programmatic SEO analysis and planning |

## Scoring Methodology

### SEO Health Score (0-100)
Weighted aggregate of all categories:

| Category | Weight |
|----------|--------|
| Technical SEO | 25% |
| Content Quality | 25% |
| On-Page SEO | 20% |
| Schema / Structured Data | 10% |
| Performance (CWV) | 10% |
| Images | 5% |
| AI Search Readiness | 5% |

## Sub-Skills Orchestrated

This skill coordinates specialized sub-skills for deep vertical analysis:
1. `seo-technical-audit` — Crawlability, indexability, security, CWV
2. `seo-content-strategy` — E-E-A-T, readability, thin content
3. `seo-geo-local` — AI Overviews / GEO optimization
4. `seo-programmatic` — Programmatic SEO analysis and planning
5. `seo-schema-markup` — Specialized structured data implementation
