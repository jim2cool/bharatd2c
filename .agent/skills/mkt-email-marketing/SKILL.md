# Email Marketing Sequences

## Core Principles
1. **One Job Per Email**: Don't confuse the reader. One goal, one CTA.
2. **Value First**: Provide useful content before asking for a sale.
3. **Relevance Over Volume**: Use triggers and segmentation.
4. **Clear Path Forward**: Every email should guide the user to the next logical step.

## Sequence Types
- **Welcome Sequence**: Post-signup indoctrination and value delivery.
- **Onboarding Sequence**: Feature-by-feature education for new users.
- **Lead Nurture**: Moving prospects from awareness to decision.
- **Win-Back**: Re-engaging inactive subscribers.

## Copy Guidelines
- **Subject Lines**: Short, curiosity-inducing or benefit-driven.
- **Preview Text**: Supports the subject line to increase open rates.
- **Formatting**: Use short paragraphs and white space for mobile readability.
- **Tone**: Conversational and personalized.
