# Programmatic SEO

## Core Principles
1. **Unique Value**: Every page must have differentiated, valuable content (not just swapping variables).
2. **Proprietary Data**: Use first-party data, surveys, or product insights for better defensibility.
3. **Internal Linking**: Implement hub-and-spoke architecture to ensure indexability.
4. **Intent Match**: Ensure automated pages actually answer user queries.

## Playbooks
- **Comparisons**: [Brand A] vs [Brand B]
- **Locations**: [Service] in [City]
- **Integrations**: [Product X] [Product Y] Integration
- **Templates**: [Type] Templates (e.g., Resume templates)
- **Directories**: Best [Category] Tools

## Strategy Framework
- Keyword Pattern Research: Identify high-volume, repeatable tail-term patterns.
- Template Design: Create layouts that maximize "unique" content per variation.
- Indexing: Manage XML sitemaps and ensure all pages are within 3 clicks from root.
