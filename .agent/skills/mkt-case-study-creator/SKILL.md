# Case Study Builder

## The Results Hierarchy
1. **Hard Data**: "$X revenue increase", "Y hours saved".
2. **Direct Quotes**: Transformational testimonials in the client's words.
3. **Process Clarity**: "How we solved the problem" (Step 1, 2, 3).
4. **Secondary Benefits**: Improved team morale, faster decision making.

## Case Study Formats
- **The Two-Liner**: For bios, proposals, and landing page social proof.
- **The Narrative Post**: For LinkedIn or newsletters (Transformation story).
- **The Full Case Study**: For website (Problem -> Solution -> Results).

## Checklist for Success
- [ ] Clear "Hero" (The Customer).
- [ ] Relatable "Villain" (The Problem/Status Quo).
- [ ] Measurable Transformation.
- [ ] Frictionless CTA ("See how we can do this for you").
